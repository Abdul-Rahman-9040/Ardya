# Image Drop Guidelines for Ardya Homestays

When you download the original property photographs from the Google Drive folder:
https://drive.google.com/drive/folders/1iRjS2tbBOLkXTnKMixC0UzTZ-HDriNYU?usp=sharing

Paste or save the photos directly into the following pre-created folders in `public/images/`:

### 1. Exterior Photos:
Save to: `public/images/exterior/`
- `main-exterior.jpg` (Hero image, front elevation)
- `entrance.jpg` (Main entrance, sit-out veranda)
- `surroundings.jpg` (Surrounding landscape / coffee flora)

### 2. Arabica Rooms:
- Room 1: `public/images/arabica/arabica-1/`
  - `cover.jpg`
  - `photo-1.jpg`
  - `photo-2.jpg`

*Note: All components use the `SafeImage` component with built-in fallback UI and graceful loaders, so your site looks clean even before files are pasted.*
